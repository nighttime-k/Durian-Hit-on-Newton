# Durian Hit on Newton

A bilingual Thai/English interactive physics infographic exploring one extremely important scientific question: what if a durian — not an apple — fell on Newton?

## Features

- Thai / English language toggle
- Apple vs. durian impact-energy comparison
- Interactive drop-height physics lab
- Alternate-history timeline
- Impossible durian voyage map
- Interactive before/after comparison

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:8080`.

## Production build

```bash
npm run build
npm run preview
```

## Stack

React 19, TanStack Start / Router, Vite, Tailwind CSS 4, TypeScript.

## Notes

This repository contains the standalone application source. Preview-platform metadata, generated deployment files, local environment files, and credentials are intentionally excluded from version control.
